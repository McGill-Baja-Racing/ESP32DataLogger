# Telemetry System Operating Guide

### Activate Sensors
1. Ensure Buck converters are connected to system wiring harness.
2. Ensure that the master node is on one end of the CAN line and the engine RPM is on the other extremity. They contain the 120 ohm resistors.
3. Turn on battery
4. Confirm all system is operational with live telemetry check

### Observe live data
1. Connect to BajaDaq wifi
2. Open browser and access the following endpoint: hhtp://192.168.4.1
3. Start the data, select sensors and enable live data.


### Extract and Filter Data
1. Connect to BajaDaq wifi
2. Open browser and access the following endpoint: hhtp://192.168.4.1
3. Open downloaded csv
4. Select entire columns of table and press CTRL+T on window to create a table.
